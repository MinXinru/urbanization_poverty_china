# Supplementary Fig. S20

Standalone package containing the plotting script, weighted aggregate tables and figure. No raw CFPS data or individual-level records are included. The plotted sample retains person-wave observations with valid household economic type and positive survey weights. Run `python code/plot.py` from this folder. Dependencies: Python 3.10+, Pillow. Outputs are written to `output/`.
